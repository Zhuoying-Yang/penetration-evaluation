# Type C — sustained solid-boundary straddling

This folder preserves the ERIS V3-C / Type C research scripts without claiming one is a complete final pipeline.

The approach uses reference-frame contrast and sustained evidence that an object remains partly on each side of a solid wall, including cases such as a banana appearing embedded through a drawer wall.

Files include `penetration_agent0_v3C_literal.py`, `penetration_agent0_v3C_multiframe.py`, Qwen batch/verifier variants, and Gemini audit/stage-2/original-prompt implementations. Dependency on original ERIS/Wilson code and datasets remains.

Before treating a single Type C variant as a final benchmark metric, inspect experiment logs and confirm which script, prompt, model and sample selection were used. Do not infer performance from the mere existence of files.
