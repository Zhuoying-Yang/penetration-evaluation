# Research code freeze — 2026-10-10

This branch snapshots **Type A Forward, Type A Backward (Reverse), and Type C** work.

## Terminology

| Subtype | What is evaluated | Current status |
| --- | --- | --- |
| Type A Forward | An actor apparently crosses a solid container boundary outside-to-inside, rather than through the legal opening | **Existing frozen baseline** on `main`. Original top-level code is untouched. |
| Type A Backward / Reverse | Reverse-direction boundary transition (inside-to-outside), or a moving solid panel apparently sweeping across a gripper/actor without an observed valid clearance path | **Experimental code snapshot**, not validated end-to-end. |
| Type C | A manipulated object remains straddling/embedded through solid material, i.e. sustained boundary-straddling | **Experimental code snapshot**, not validated end-to-end. |

A wall edge moving past a stationary gripper is a *relative* crossing event; it is not necessarily an object moving IN-to-OUT. Both are kept in the reverse diagnostic family for continuity, but should be separated if later tests establish different failure mechanisms.

## Layout

- Top-level Type A Forward scripts and `README.md`: **unchanged** from `main`.
- `type_a/backward/eris/`: Qwen candidate/reverse experiments and Gemini diagnosis scripts copied from ERIS.
- `type_a/backward/mac/`: image preparation, multi-scale crops, and GPT-6 Sol trajectory prompt used on Mac through lab gateway.
- `type_a/backward/diagnostics/`: tracking/geometry investigations **not** used as a final verifier.
- `type_c/eris/`: Type C Qwen/Agent0/Gemini experiment versions copied from ERIS.

## Type A Backward: latest diagnostic

- Stage 1 full-video Qwen candidate scans exist on ERIS, but the GPT-6 Sol tests on `0055/0056/0057` used **manually selected windows**, not Qwen-selected windows.
- Type A backward trajectory prompt V3 used 13 chronological crops plus one full scene image and five tight focus crops (19 images in total), in the lab gateway.
- Development-only scores on the three selected seed103 examples: 0055 (negative) = **0.24**, 0056 (suspected positive) = **0.34**, 0057 (suspected positive) = **0.46**.
- These cases were repeatedly inspected and used for prompt development. This is **not held-out evaluation**, an AUROC claim, or evidence of accurate 3D intersection recovery.
- Qwen/CoTracker attempts on the transparent wall had significant uncertainty or landmark drift. Do not represent those diagnostics as the freeze's proven detector.

## Type C: current snapshot

- Agent0 / Qwen V3-C reference-frame comparison and persistence and later Type C batch/verification/Audit code are included as research snapshots.
- Reference-frame contrast and persistent evidence are intended to detect **sustained straddling**, distinct from a single-frame Type A crossing.
- No claim is made that the collected scripts are a standalone, fully configured or benchmark-validated pipeline. Some reference external Wilson runtime, checkpoints and original ERIS paths.

## Security / reproducibility

- No videos, original outputs, weights, .env files, API keys, or user annotations are deliberately included.
- Code includes hard-coded cluster paths that must be configured in another environment.
- Model scores refer to **visual plausibility**, not calibrated penetration probabilities or proof of collision.
- The branch is a snapshot, not a replacement for the existing Forward baseline.
